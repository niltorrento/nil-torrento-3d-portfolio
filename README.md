Personal portfolio website for my 3D Generalist / VFX work.

## Folder structure

```text
.
├── index.html              # Page content and project descriptions
├── css/
│   └── style.css           # All visual styling: colours, spacing, layout, responsive design
├── code/
│   └── java.js             # Small interactions (mobile menu and footer year)
└── images/
    ├── projects/           # Project renders, thumbnails and breakdown images
    └── social_media/       # Logos and social icons, if needed
```

## How to edit the site

- **Text, section titles, project names, links:** edit `index.html`.
- **Colours, fonts, spacing, image sizes and mobile layout:** edit `css/style.css`.
- **Menu behaviour and small interactions:** edit `code/java.js`.
- **Project images:** upload them to `images/projects/`, then update the relevant project in `index.html`.

Keep file names lowercase and use hyphens instead of spaces, for example `la-monja-gitana-main.jpg`.

## Local preview

Open `index.html` in a browser to preview the page. For the most accurate preview, use a local development server because browser behaviour can vary when opening files directly.

## Publishing

This repository is intended for GitHub Pages. The custom domain `niltorrento.com` can be connected later in the repository's **Settings → Pages** once the domain has been registered and its DNS configured.
